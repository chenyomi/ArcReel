# 新弹力样本册

温岭鞋厂的微信小程序。客户看分类和货号，打电话询价。价格空着显示「询价」，没有购物车。

数据和图片在这个小程序的微信云开发里。不部署阿里云，也不用七牛。目录里的 `server/` 是早先的自建接口，不要拿去上线。

用微信开发者工具打开 `miniprogram/`。

## 第一次打开

1. 把 `miniprogram/project.config.json` 里的 `touristappid` 换成鞋厂小程序的 AppID。
2. 开发者工具里点「云开发」，开通环境。地域选上海或广州。
3. 在 `cloudfunctions/admin` 上右键「上传并部署：云端安装依赖」。
4. 云数据库建三个集合：`categories`、`products`、`site`。权限先按下面设好，再给别人看。
5. 云存储权限选「所有用户可读，仅创建者可写」。
6. 手机或电脑微信预览小程序，打开「介绍」页最底下的「管理」。页面上有一串 openid。
7. 云开发控制台 → 云函数 `admin` → 配置 → 环境变量，增加 `ADMIN_OPENIDS`，值就是这串 openid。几个人用英文逗号隔开。保存后重新上传这个云函数。
8. 再进「管理」，点「写入初始分类和联系方式」。然后在「款式」里添加货号和配色图。

电脑上改货：用电脑版微信打开同一个小程序，进「介绍 → 管理」。

## 数据库权限

`categories` 和 `site` 用自定义规则：

```json
{ "read": true, "write": false }
```

`products` 用自定义规则，下架的款客户读不到：

```json
{ "read": "doc.published == true", "write": false }
```

写入都走云函数 `admin`，云函数不受这两条规则限制。

## 客户能看到的

首页、分类、上新、详情、联系、介绍。一个货号是一批配色。底部是拨打电话和复制微信。纬度和经度都在「联系与介绍」里填上之后，联系页才能导航。
